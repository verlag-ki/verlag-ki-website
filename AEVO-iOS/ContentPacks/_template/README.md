# Leere Vorlage

Dieser Ordner ist absichtlich noch nicht valide. Er darf nicht versehentlich als fertiger Inhalt in einer App erscheinen. Fülle alle Dateien gemäß `CONTENT_PACK_SCHEMA.md` und den JSON-Schemas aus. Für vollständige syntaktische Beispiele siehe `ContentPacks/demo-orbit/`.
